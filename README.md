# MathLab

Interactive mathematics learning app built with Streamlit.

## Deploy on Streamlit Community Cloud
1. Upload `app.py` and `requirements.txt` to a GitHub repository.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Create an app, select the repository and `main` branch, and set the main file path to `app.py`.
4. Click Deploy.

Dependencies are listed in `requirements.txt`.
